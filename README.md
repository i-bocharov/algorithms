# Data Structures & Algorithms

A personal repository dedicated to mastering problem-solving patterns, data structures, and algorithmic thinking.

## 🛠️ Tech Stack & Methodology

* **Python** — Each solution is implemented in Python to develop and practice the core algorithm, with a focus on logical clarity and readable code.

* **TypeScript** — Each solution is also implemented in TypeScript to practice the language, strict typing, different syntax, and differences in function and language behavior.

## 📁 Repository Structure

The project is structured by topics. Each problem has its own isolated folder containing implementations in both languages and a bilingual conceptual breakdown:

```text
algorithms/
│
├── arrays/
│   └── remove_duplicates/
│       ├── main.py
│       ├── main.ts
│       └── DISCUSSION.md  <-- Conceptual breakdown (EN/RU)
│
└── .gitignore
```

## ✍️ Discussion Format

Every problem folder includes a `DISCUSSION.md` file. It covers:

1. Problem clarification and constraints
2. Approach selection and justification
3. Step-by-step algorithm description
4. Complexity analysis (Time & Space Complexity)
